# survey_plot

This repo contains materials for Plotting for Survey Research, a session designed to show how to use data visualisation to check your data for problems and tell a story about results. 

There are two resource documents. 

One walks through the process using R code, for those who are familiar with the `ggplot` package. 

Another does the same set of steps, using open source GUI based software JAMOVI, and the vijPlots module, for students who are not familiar with code.
